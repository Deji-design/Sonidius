# Sonidius
Sonidius is a Python application designed to help beginners develop a strong foundation in music by focusing on note recognition and fundamental music theory concepts. It provides an engaging environment that encourages learners to develop musical skills with confidence. 

## Motivation
Sonidius was inspired by the observation that children, within the age range of 6 and 15, have limited exposure to basic music concepts. Similar to how literacy education is prioritized due to its importance in language, music foundation should be built in people to ensure effective expression through sound. This projects aims to bridge the gap by using technology to create an engaging environment for young learners.


## Future goals
Future versions aim to introduce interactive lessons, quizzes, personalized learning while tracking user's progress to ensure an adaptive learning experience.
